# Ad-Tech Campaign Performance Dashboard

## Project Overview

This project analyzes advertising campaign performance to understand **which campaigns are generating the most efficient return on advertising spend and what factors are influencing overall campaign performance**.

The dashboard was designed to help identify opportunities to **optimize campaign performance, understand profitability, and support data-driven advertising budget allocation**.

## Business Question

> **“ Which campaigns are driving the most efficient return on advertising spend, and what factors are influencing campaign performance so that we can identify where to optimize or reallocate the advertising budget? ”**

## What This Dashboard Answers

The dashboard provides insights into:

* Which campaigns are generating the **highest revenue, profit, and ROAS**
* Which campaigns are delivering strong revenue but may not be equally **profitable or efficient**
* How **ad formats, channels, devices, and countries** influence campaign performance
* How advertising performance changes over **time**
* Which campaigns represent potential opportunities for **optimization or budget reallocation**
* The relationship between **advertising spend and revenue**
* How efficiently advertising spend is being converted into revenue using key Ad-Tech performance metrics

## Key Metrics

The dashboard tracks important advertising performance KPIs including:

**Impressions, Clicks, CTR, Conversions, Conversion Rate, Ad Spend, Revenue, CPC, CPA, and ROAS.**

These metrics provide a comprehensive view of both **campaign volume and efficiency**, rather than evaluating campaigns based on revenue alone.

## Data Preparation & Quality

Before building the dashboard, the dataset was reviewed for data quality issues. The data preparation process included identifying and correcting issues such as **missing values, inconsistent data, incorrect data types, and invalid records** to ensure that the analysis was based on reliable and consistent data.

The cleaned dataset was then transformed and modeled for analysis in Power BI.

## Tools Used

* **Microsoft Excel** – Initial data inspection and data quality analysis
* **Power Query (M)** – Data cleaning and transformation
* **Power BI** – Data modeling, DAX calculations, visualization, and dashboard development
* **DAX** – Creation of analytical measures and advertising KPIs

## Outcome

The final dashboard provides a consolidated view of campaign performance and allows users to move beyond simply identifying the highest-revenue campaigns. It highlights **efficiency, profitability, and performance drivers**, helping determine where advertising budgets may be better optimized or reallocated.
